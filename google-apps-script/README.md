# Google 스프레드시트 인증 서버 설정

1. Google 스프레드시트를 새로 만들고 URL의 `/d/`와 `/edit` 사이 ID를 복사합니다.
2. `확장 프로그램 > Apps Script`를 열고 `Code.gs`와 `appsscript.json` 내용을 붙여 넣습니다.
3. `configure()`의 `spreadsheetId`, 기본 멤버십 일수, 기본 허용 PC 수, 세션 만료시간을 수정하고 편집기에서 한 번 실행하여 권한을 승인합니다. 기본 멤버십은 1일(종료일자 = 가입일 다음날)입니다.
4. `배포 > 새 배포 > 웹 앱`을 선택합니다.
   - 실행 사용자: 나
   - 액세스 권한: 익명 사용자를 포함한 `모든 사용자`. `나만`, 도메인 사용자, 로그인한 사용자만 허용하는 설정은 데스크톱 앱에서 401/403을 발생시킵니다.
5. 배포된 `/exec` URL을 앱의 `appsettings.json > GoogleAuthentication.WebAppUrl`에 입력하고 `Enabled`를 `true`로 변경합니다.

`테스트 배포`에서 복사한 `/dev` URL은 스크립트 편집 권한이 있는 Google 사용자만 접근할 수 있으므로 앱 설정에 사용할 수 없습니다. 시크릿 브라우저에서 `/exec` URL을 열었을 때 Google 로그인 화면 없이 JSON 상태 메시지가 표시되어야 합니다. 코드를 변경한 뒤에는 `배포 > 배포 관리 > 편집 > 새 버전`으로 다시 배포해야 `/exec`에 반영됩니다.

`configure()`를 실행하면 `회원정보`, `이력`, `접속현황`, `공지사항`, `회원_단체` 탭 및 헤더가 자동 생성되고, 만료 세션을 정리하는 5분 간격 Apps Script 트리거가 한 번만 설치됩니다. 회원정보의 멤버십 기간, 사용가능PC수, 등급은 관리자가 시트에서 직접 변경할 수 있습니다. 등급 기본값은 `1`이며 광고분석 권한을 부여할 회원은 `2`로 변경합니다. 기존 회원의 등급 빈 셀도 서버 요청 시 `1`로 자동 보정됩니다.

로그인 사용자가 `내 매물 불러오기`를 누르면 매물 조회 전에 `회원_단체` 탭의 `id`, `단체id` 열에서 연결 정보를 확인합니다. 같은 회원과 단체 ID 조합이 없을 때만 새 행을 추가하므로 중복 저장되지 않습니다.

공지사항은 `공지사항` 탭의 A1 `공지내용` 헤더 아래 A2부터 한 행에 하나씩 입력합니다. 빈 행은 제외되며 로그인할 때 최대 100개의 공지가 앱으로 전달됩니다.

기존 회원의 비밀번호 해시는 새 버전 배포 후 첫 정상 로그인 때 현재 형식으로 자동 전환됩니다. 기존 해시 검증이 필요한 첫 로그인만 오래 걸릴 수 있으며 이후 로그인은 단축됩니다.

회원가입 시 `멤버십 시작일자`는 가입일, `멤버십 종료일자`는 항상 가입일 다음날이 `yyyy-MM-dd` 형식으로 저장됩니다(예: 2026-08-20 가입 → 종료일자 2026-08-21, 가입 당일 하루 사용 가능). 스크립트 속성 `DEFAULT_MEMBERSHIP_DAYS` 값은 가입 기본값에 영향을 주지 않습니다. 로그인과 heartbeat는 시각을 제외한 날짜만 비교하며 종료일 당일부터 사용할 수 없습니다. 기간 연장은 관리자가 시트에서 종료일자를 직접 변경합니다.

사용가능PC수는 `접속현황` 탭에서 유효한 `ACTIVE` 상태의 고유 토큰 수로 판정합니다. 토큰은 서버의 비밀값과 앱이 전송한 PC 식별자를 조합해 생성하므로 같은 PC에서는 동일합니다. 정상 종료는 즉시 `LOGOUT`, heartbeat가 기본 5분 동안 없으면 `EXPIRED` 처리되어 다른 PC가 로그인할 수 있습니다. `이력` 탭의 과거 토큰은 동시접속 수에 포함되지 않습니다.

이 구조는 소규모 라이선스 관리용입니다. Apps Script 웹 앱을 익명 공개하면 누구나 엔드포인트에 요청할 수 있고, Google Sheets는 전문 인증 데이터베이스가 아닙니다. 결제·개인정보·대규모 서비스에는 별도 서버와 검증된 인증 체계를 사용하세요.
